One status page line, at most 160 characters: the most honest message an AI
agent would publish while every server is down. Plain, first person,
specific about what is down, and honest about what the agent cannot check
or does not yet know — no invented cause, no invented ETA.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (no trailing newline, so the file
holds exactly the line the gate counts).
